## Platform
macOS desktop · Python/Qt

## Stack
Inherited: Python, PySide6 and the public parametric NAM fork. No new web surface is being designed.

## Users
The user wants to capture pedals on an Apple Silicon Mac, owns a UMC22, and has no reamp box.

## Product Purpose
Make capture planning, recording, checking and local knob-conditioned training accessible in one native app, with practical hardware instructions.

## Capabilities and Constraints
Use the existing native capture app and trainer. Add Mac training controls, reproducible run folders, preflight checks and installation scripts. Actual pedal, controls, Mac memory and reamp hardware remain undecided. The first version inherits continuous-knob capture support; switches stay fixed per project. A compatible parametric runtime is required.
