# Interface fonts

Geist (interface text) and Geist Mono (numbers) are the faces of the approved Console redesign (`docs/superpowers/specs/2026-10-17-ux-redesign-design.md`). The app bundles the foundry's own static TTF files, unchanged, so Qt selects real weights on every platform.
