# Native design handoff

The user approved the quiet light desktop utility in the original mockups, then reported that the native app looked dated beside those screenshots. This refinement brings the native typography, controls and density closer to the approved direction while preserving real capture, training, saved projects, switch layouts and the recently added NAM A2 Standard + Nano options. [Root DESIGN.md](../../DESIGN.md) and [.impeccable/design.json](../../.impeccable/design.json) record the current implementation. Historical [mockup design](../mockups/DESIGN.md), [workflow screenshots](../mockups/overview.html) and [Plan refinement](../mockups/plan-quality.md) remain references; their synthetic browser data and creation-time disclaimers are intact.

The theme is owned by [theme.py](../../parametric_mac/theme.py), with component painting and geometry in [gui.py](../../parametric_mac/gui.py); the old inline `gui.py` style block is no longer the source. The initial window remains 1140 × 840px, with a 760 × 580px minimum. Evidence covers 1140 × 900px and 800 × 680px. Longer lists, advanced tables and compact pages scroll; stage actions remain pinned. There is no phone navigation pattern or fabricated HTML/CSS preview of the native components.

The [evidence manifest](../../.impeccable/review/native/evidence.json) identifies **20 actual Linux Qt offscreen images**: ten stage/viewport views, six additional Plan/job states and four amp editor/target views. The current images include corrected disabled training-profile styling and synchronized error-log disclosure. Capture fixtures have pending plans and no physical recording. Review uses an actual synthetic CPU export.

The full suite passed **57 tests in 74.45 seconds**, with **10 upstream Lightning deprecation warnings**. The final targeted GUI test passed in **30.94 seconds** after the two state corrections. Wheel asset inclusion was verified for all **15 bundled UI assets**. These checks establish application integration and asset packaging; they do not establish hardware sound quality.

Previous [native finish](native-finish-review.md) and [controls/fidelity](native-controls-review.md) reviews are historical: the user's dated-appearance feedback superseded their earlier ship conclusion. The fresh reviewer’s final disposition is **ship**. Disabled training profiles, error-log disclosure synchronization and persistence documentation are all resolved. The final wheel inventory contains 15 verified UI assets; no material findings remain. See the [current restyle review](native-modern-review.md).

Mac installation, CoreAudio hardware recording, full MPS training, real-pedal/amp model accuracy and Mac VoiceOver remain unverified. The existing detector exception applies only to Inter in historical `docs/mockups/styles.css`; no native ignore or new suppression was added. Native Inter is intentional fidelity to the approved face, backed by bundled assets. The sidecar records actual source, state and evidence metadata without invented tonal ramps, browser metrics or native HTML/CSS previews.
