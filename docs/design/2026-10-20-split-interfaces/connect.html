Split interfaces on Connect

Connect stage 2 when a sound card appears to macOS as two one-direction devices. Drawn on the real Phase 2 Connect layout. Dark theme.

A · A split interface is one sound card

macOS shows the UMC22 (“USB Audio CODEC”) as an output-only and an input-only device with the same name. Connect pairs them into one entry, in the same list as every other card. The channel counts help tell cards apart.

D · The two halves run at different rates

Each half has its own sample rate in Audio MIDI Setup. Both must match the capture signals (48 kHz). The existing rate message and button name the half that is wrong.
